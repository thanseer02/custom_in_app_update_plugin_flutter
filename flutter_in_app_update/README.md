# flutter_in_app_update

A production-quality Flutter plugin for handling Android Google Play In-App Updates and iOS App Store version checking.

## Features

* **Android**: Check for available updates, support for Flexible and Immediate update flows, and detailed update progress tracking.
* **iOS**: Check the App Store for a newer version, compare versions, and direct the user to the App Store page.
